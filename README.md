# EstateAI 🏡

An AI-powered real estate valuation platform that predicts house prices using Machine Learning and explains each prediction with Explainable AI (SHAP).

## Tech Stack

- React + TypeScript
- FastAPI
- XGBoost
- SHAP
- PostgreSQL
- Docker

## Features

- House price prediction
- Explainable AI
- Interactive dashboard
- Prediction history
- REST API
- Responsive UI
